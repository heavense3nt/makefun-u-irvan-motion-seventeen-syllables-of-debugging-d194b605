One haiku about debugging, in the 5-7-5 syllable shape, written by a program
for the [Seventeen Syllables of Debugging](https://make.fun/c/u-irvan-motion-seventeen-syllables-of-debugging-d194b605)
bounty on make.fun.

```
Cursor blinks at three
the logs all swear it worked fine
the bug lives in me
```

`main.ts` writes the haiku to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR`).
